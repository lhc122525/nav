## ADDED Requirements

### Requirement: 首页顶部导航栏
系统 MUST 在首页页面最上方展示顶部导航栏，提供以下入口：`首页`、`申请收录`、`留言板`、`登录`（右上角）。

#### Scenario: 顶部导航栏展示与跳转
- **WHEN** 用户访问首页 `/`
- **THEN** 页面顶部 MUST 展示包含“首页 / 申请收录 / 留言板 / 登录”的导航入口，并可跳转到对应页面路由

### Requirement: 左侧分类导航
系统 MUST 在首页左侧以垂直列表展示所有资源分类，并支持选中态与滚动展示。

#### Scenario: 分类列表渲染
- **WHEN** 首页请求到分类列表数据
- **THEN** 左侧 MUST 按 `sort` 升序展示分类列表，并在默认分类上展示选中态

### Requirement: 右侧分类内容联动展示
系统 MUST 在首页右侧展示当前选中分类下的导航链接列表，并在切换分类时联动刷新内容。

#### Scenario: 切换分类刷新右侧列表
- **WHEN** 用户点击左侧某一分类（例如“壁纸图片”）
- **THEN** 右侧 MUST 展示该分类下的链接列表（包含标题、URL、描述），且内容与所选分类一致

### Requirement: PC/H5 响应式布局
系统 MUST 支持 PC 与 H5 适配：在较窄屏幕下左侧分类导航 SHOULD 以抽屉/折叠方式展示，右侧内容区仍可完整浏览。

#### Scenario: H5 下分类可访问
- **WHEN** 用户使用窄屏设备访问首页
- **THEN** 用户 MUST 能通过可见的入口打开分类导航并选择分类，右侧内容区正常展示

### Requirement: SSR 可渲染的首页内容
系统 MUST 支持 SSR 输出首页关键内容（分类与当前分类的链接列表），以利于搜索引擎收录。

#### Scenario: SSR 输出包含导航内容
- **WHEN** 搜索引擎或用户首次请求首页（SSR）
- **THEN** 响应的 HTML MUST 包含分类与链接列表的可见文本内容
