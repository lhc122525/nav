## ADDED Requirements

### Requirement: 申请收录页面入口
系统 MUST 在顶部导航栏提供“申请收录”入口，并提供申请收录页面用于提交新网址。

#### Scenario: 从首页进入申请收录页
- **WHEN** 用户点击顶部导航栏的“申请收录”
- **THEN** 系统 MUST 跳转到申请收录页面并展示提交表单

### Requirement: 申请收录提交表单
系统 MUST 提供提交表单，至少包含：站点标题、站点 URL、简短描述；允许填写联系方式（可选）。

#### Scenario: 表单字段校验
- **WHEN** 用户提交表单且缺少标题或 URL
- **THEN** 系统 MUST 拒绝提交并提示必填项

### Requirement: 申请收录提交接口
系统 MUST 提供公开提交接口以接收申请收录数据，并将记录保存为 `pending` 状态，供后台后续处理。

#### Scenario: 提交成功入库
- **WHEN** 用户提交合法的标题、URL、描述（以及可选联系方式）
- **THEN** 系统 MUST 创建一条 `pending` 状态的申请记录并返回成功结果

### Requirement: 提交频率与安全基线
系统 MUST 对公开提交接口具备基础的滥用防护能力（例如基于 IP 的简单限流或同一 URL 的重复提交约束）。

#### Scenario: 重复提交受限
- **WHEN** 同一用户在短时间内对同一 URL 多次提交
- **THEN** 系统 MUST 拒绝或合并重复提交并返回可理解的错误信息
