## ADDED Requirements

### Requirement: 分享资源列表管理
后台 MUST 提供分享资源分页列表，支持按标题关键字搜索，并支持多选批量删除与单个删除。

#### Scenario: 分页与搜索
- **WHEN** 管理员打开分享资源页
- **THEN** 系统按创建时间倒序分页返回资源列表（含标题、类型、地址、文件大小、说明、创建时间）
- **WHEN** 管理员输入标题关键字并搜索
- **THEN** 系统仅返回标题包含关键字的资源

#### Scenario: 单个删除为真实删除
- **WHEN** 管理员对一条资源执行删除并确认
- **THEN** 系统删除该数据库记录
- **THEN** 若该资源为上传文件类型，系统同时删除服务器上对应的物理文件

#### Scenario: 批量删除
- **WHEN** 管理员勾选多条资源并执行批量删除且确认
- **THEN** 系统删除所有勾选记录
- **THEN** 系统删除其中文件类型资源对应的物理文件
- **THEN** 删除完成后列表刷新并清除勾选状态

### Requirement: 新增资源支持三方 URL 与上传文件
系统 MUST 支持两种资源来源：三方 URL 与上传文件到服务器，且一条记录对应一个 URL 或一个文件。

#### Scenario: 新增三方链接资源
- **WHEN** 管理员选择"三方链接"类型并提交标题与合法的 http(s) 地址
- **THEN** 系统创建类型为 url 的资源记录

#### Scenario: 上传文件生成可访问地址
- **WHEN** 管理员选择"上传文件"类型并上传文件
- **THEN** 系统将文件保存到服务器 uploads/share 目录并生成站点可访问地址
- **THEN** 提交后系统创建类型为 file 的资源记录（记录原始文件名与文件大小）

#### Scenario: 非法地址被拒绝
- **WHEN** 管理员提交 url 类型资源但地址不以 http(s):// 开头，或 file 类型资源地址不在本站 /uploads/ 下
- **THEN** 系统拒绝创建并返回可理解的错误信息

### Requirement: 编辑资源
系统 MUST 支持编辑资源标题、地址/文件与说明；文件类型资源替换文件时，旧物理文件 MUST 被删除。

#### Scenario: 编辑链接资源
- **WHEN** 管理员修改链接资源的地址或说明并保存
- **THEN** 系统更新记录且不涉及文件操作

#### Scenario: 替换上传文件
- **WHEN** 管理员编辑文件类型资源并上传新文件替换后保存
- **THEN** 系统保存新文件地址（含新文件名与大小）
- **THEN** 系统删除被替换的旧物理文件

### Requirement: 分享生成外部可访问二维码
管理员点击分享时系统 MUST 生成可被外部访问的二维码；扫码即访问三方地址或站点文件地址。

#### Scenario: 分享资源展示二维码
- **WHEN** 管理员点击某条资源的"分享"
- **THEN** 系统在弹窗中展示二维码与完整访问链接
- **WHEN** 外部用户扫码
- **THEN** 可直接访问该资源（三方链接直达目标地址，上传文件直达站点下载地址）

#### Scenario: 复制与打开链接
- **WHEN** 管理员在分享弹窗中点击复制链接
- **THEN** 完整链接被复制到剪贴板并提示成功
- **WHEN** 管理员点击打开链接
- **THEN** 系统在新窗口打开该资源地址
