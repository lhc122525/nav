## Why

当前导航站仅具备基础“链接列表 + OpenAPI”能力，缺少可面向用户的完整首页信息架构（顶部导航、左侧分类、右侧内容联动）与可运营的后台管理能力（分类/链接增删改、管理员登录）。这会导致首页内容不可持续维护、收录入口不可用、SEO 结构不清晰。

本变更将把“导航列表”从 demo 升级为可使用的产品骨架：用户可浏览分类与站点列表；管理员可维护分类与链接；同时提供申请收录与留言板入口以承接增长与反馈。

## What Changes

- 首页信息架构落地：顶部导航栏、左侧分类导航、右侧内容展示区联动（点击分类刷新右侧列表）。
- 申请收录页：提供提交新网址的表单与后端接口（后续可人工审核/入库）。
- 留言板页：提供留言提交与展示（用于反馈与建议收集）。
- 管理后台：超级管理员登录后进入后台，支持创建/管理管理员账号（初始化账号：nszm / nszm123..）。
- 后台导航管理：分类（弹窗增删改）与链接（弹窗增删改、可按分类筛选与排序）。
- API 与 OpenAPI：为首页与后台补齐所需 API，并在 OpenAPI 文档中同步可用接口。

## Capabilities

### New Capabilities

- `home-navigation-page`: 首页顶部导航 + 左侧分类 + 右侧链接列表联动展示。
- `public-submission-intake`: 申请收录（提交新网址）页面与提交接口。
- `public-guestbook`: 留言板页面与留言提交/查询接口。
- `admin-auth`: 超级管理员登录与管理员账号管理（含初始化账号）。
- `admin-navigation-management`: 后台导航管理（分类/链接的弹窗增删改、列表筛选排序）。

### Modified Capabilities

- (none)

## Impact

- 前端：新增/调整首页布局与交互；新增申请收录页、留言板页、后台页面与路由入口。
- 后端：新增管理员认证、管理员管理、申请收录、留言板等 API；补齐分类/链接查询与管理接口的能力边界与校验。
- 数据库：引入管理员、申请收录、留言板等表结构（在 dev/db/init.sql 中维护并初始化默认账号）。
- OpenAPI：扩展 `/api/openapi.json` 的 paths 与 schema，确保文档与实际接口一致。
