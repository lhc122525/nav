## ADDED Requirements

### Requirement: 后台导航管理入口
系统 MUST 在后台提供“导航管理”菜单入口，用于维护首页的分类与链接数据。

#### Scenario: 后台可进入导航管理
- **WHEN** 管理员登录成功进入后台
- **THEN** 系统 MUST 提供“导航管理”入口并展示分类区与链接区

### Requirement: 分类管理（弹窗增删改）
系统 MUST 允许管理员通过弹窗创建、编辑与删除分类，并支持配置 `name`、`slug`、`sort`。

#### Scenario: 新增分类
- **WHEN** 管理员在分类区域点击“新增”并提交合法的 `name` 与 `slug`
- **THEN** 系统 MUST 创建分类记录并在列表中可见

### Requirement: 分类唯一性约束
系统 MUST 保证分类 `slug` 全局唯一；当提交重复 `slug` 时 MUST 返回可理解的错误信息。

#### Scenario: 重复 slug 被拒绝
- **WHEN** 管理员创建或更新分类时使用已存在的 `slug`
- **THEN** 系统 MUST 拒绝提交并返回错误信息

### Requirement: 链接管理（弹窗增删改）
系统 MUST 允许管理员通过弹窗创建、编辑与删除链接，并支持配置：所属分类、标题、URL、描述、图标 URL、启用状态、排序值。

#### Scenario: 新增链接并归类
- **WHEN** 管理员创建链接并选择某一分类
- **THEN** 系统 MUST 创建链接记录并在对应分类筛选结果中可见

### Requirement: 链接列表筛选与排序
系统 MUST 支持在后台按分类筛选链接，并支持关键字搜索（标题/URL/描述）；链接列表 MUST 按 `sort` 升序、再按 `id` 倒序排序。

#### Scenario: 按分类筛选
- **WHEN** 管理员选择某一分类作为筛选条件并执行查询
- **THEN** 系统 MUST 仅返回该分类下的链接记录

### Requirement: 删除分类的处理策略
系统 MUST 对删除分类提供一致的处理策略：若分类下存在链接，系统 MUST 拒绝删除并提示先迁移/删除链接，或提供明确的级联删除策略。

#### Scenario: 分类下存在链接时删除受限
- **WHEN** 管理员尝试删除一个仍关联链接的分类
- **THEN** 系统 MUST 拒绝该操作并返回可理解的提示信息
